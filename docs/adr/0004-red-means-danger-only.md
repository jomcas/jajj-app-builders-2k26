# Red means danger and nothing else

Red appears only for a Deviation, the Flare, the SOS control and Emergency Guides. It is never used for branding, category tags, charts, or form errors (those use amber). A hiker under stress has to read "red = something is wrong right now" instantly, and every decorative use of red weakens that signal. Firing the Flare also takes a deliberate gesture (slide or long-press) rather than a single tap, so a pocket tap cannot set it off.

## Consequences

- The always-visible SOS control is neutral with a red icon. It turns fully red only while the Flare is active.
- Group Hike members are olive dots and turn red only when they are in Deviation.
- When a design wants red "because it looks good", the answer is no. Pick another hue.
- Red is never the only signal. A Deviation also turns the Trail line dashed and shows an icon and text, so colorblind hikers and hikers in glare still get it.
